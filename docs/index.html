Get started

Download. Configure. Run locally.

These commands run the current development scaffold, not live Microsoft 365 administration. You'll need Git, Node.js 24+, a JWT issuer you control and credentials configured outside source control.

01 · Download

Clone the public repository

Use Git or download the ZIP archive from GitHub.

git clone https://github.com/skunkworks-africa/skunkworks-365-mcp.git
cd skunkworks-365-mcp
npm install --ignore-scripts

02 · Authenticate

Configure a trusted JWT issuer

Copy the placeholders and replace the issuer, JWKS, audience and local subject grants. Do not commit the real files.

cp .env.example .env
cp access-registry.example.json access-registry.json
# Edit .env and access-registry.json

03 · Validate

Build and test

Load the environment variables from your shell or secret manager. Run the TypeScript build and authorization tests.

npm run build
npm test
npm start

04 · Local endpoint

Inspect the MCP prototype

The bearer-token protected service listens only on loopback. The Microsoft-provider tools currently report connector unavailable.

http://127.0.0.1:3000/mcp

The example .env contains nonfunctional values. To run the service, configure and supply a real signed bearer token from the trusted issuer. Never expose this prototype directly to the internet.

ChatGPT integration

Connect when the remote runtime is ready.

ChatGPT requires a reachable authenticated HTTPS MCP endpoint. This public website hosts setup documentation; it is not a connection URL.

Read the official ChatGPT custom MCP setup guide ↗

  1. Deploy the MCP runtime separately over HTTPS with a supported OAuth flow.
  2. In ChatGPT on the web, use Plugins → Add custom MCP server, where available.
  3. Enter the deployed MCP endpoint URL (often ending in /mcp), not this documentation domain.
  4. Configure authentication and review requested permissions before enabling the integration.
  5. Test access only against an authorized tenant.

Example only · Not live

https://YOUR-SECURE-HOST.example/mcp

This illustrates the format of a future deployed endpoint and must not be used as a real server address.
